# FirstIn brand deliverables

This folder contains the identity guide, editable vector marks and concept mockups, and raster exports. The live app uses the same palette and geometric mark. Read [BRAND_GUIDE.md](BRAND_GUIDE.md) for rationale, usage, palette, typography, voice, and implementation notes.

Run `npm run brand:build` to regenerate the exported assets. Raster generation uses `sharp`.
